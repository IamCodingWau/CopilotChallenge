# 🌿 Serene — Aesthetic Website

A simple, elegant, and responsive website built using **HTML, CSS, and JavaScript**. Serene features a minimal design, soft earthy colors, stylish typography, and a clean layout.

## ✨ Features

- 🎨 Minimal and aesthetic design
- 📱 Responsive layout for desktop, tablet, and mobile
- 🧭 Navigation menu with a mobile toggle
- 🌄 Custom abstract hero artwork using CSS and SVG
- 🪴 About section introducing the website
- 💡 Feature cards for creative projects, technology, and inspiration
- ✉️ Contact section with an email link
- 🔝 Smooth scrolling and back-to-top navigation
- 📅 Automatically updated copyright year
- 🧩 Separate HTML, CSS, and JavaScript files

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, animations, and responsive design
- **JavaScript** — Mobile navigation and dynamic copyright year
- **Google Fonts** — DM Sans and Playfair Display

## 📁 Project Structure


## 🚀 Getting Started

### 1. Download or Clone the Project

Download the project files and extract them into a folder.

### 2. Open the Project

Open the project folder in Visual Studio Code or your preferred code editor.

### 3. Run the Website

Open `index.html` directly in your web browser.

For a better development experience, you can use the **Live Server** extension in Visual Studio Code.

## 🎨 Customization

You can easily personalize the website:

- **Content:** Edit the text and sections in `index.html`.
- **Colors and layout:** Modify the CSS variables and styles in `style.css`.
- **Interactions:** Update the navigation behavior in `script.js`.
- **Contact email:** Replace `hello@example.com` in `index.html` with your own email address.
- **Typography:** Change the Google Fonts imported in the HTML and CSS files.

## 📱 Responsive Design

The website uses CSS media queries to adjust its layout for different screen sizes. The navigation menu becomes a mobile-friendly toggle, and the content sections adapt to smaller screens.
